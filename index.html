About

Who I am.

I'm Daniel Keya, a Full-Stack Developer based in Kisumu, Kenya, currently training at Zone01 Kisumu — an intensive, project-based coding programme where I build real software, not toy demos.

My focus is backend engineering in Go: concurrency, clean architecture, and systems built to last. I care about how code is structured, not just whether it runs.

Outside of Go I work across the full stack — Python, JavaScript, PHP, Laravel — and I'm always exploring new problem domains, from payment infrastructure to algorithmic trading.

Outside of work, my hobby is algorithmic development and quantitative trading. I design systematic strategies, code trading bots against live market data, and backtest them before risking a cent — writing the data pipeline, the signal logic, and the execution layer. It's the same discipline as backend engineering: clean logic, measurable results, no guessing.

Open to collaborations on Go projects, backend systems, developer tooling, and quantitative trading projects.
